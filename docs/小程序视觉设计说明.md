# 小程序视觉设计：方案 1「清爽校园」

## 视觉规范

使用蓝白配色、浅色背景、圆角卡片和统一线性图标。主色 `#326de5`，背景 `#f5f8fe`，正文 `#162b4d`，辅助文字 `#63758f`。全局变量与基础组件位于 `sportdocu/styles/theme.wxss`，列表页公共样式位于 `sportdocu/styles/lists.wxss`。

## 页面调整

- 首页：突出搜索、赛事推荐和赛事成绩／赛事通知／我的参赛三个入口。保留后端轮播图；没有轮播图时，推荐卡优先展示报名中的运动会，再展示进行中的运动会，最后回退到列表首项。名称、时间、场地均使用接口数据。
- 赛况：使用蓝色赛事信息卡、进行中／历史切换、项目与组别筛选，以及分轮次的成绩列表。保留加载、失败重试和空数据提示。
- 个人中心：白色身份卡，突出参赛项目和我的队伍，统一赛事通知、修改密码和退出登录入口。
- 二级页面：同步赛事详情、报名、赛程、项目、通知、团队积分及登录等页面的标题、按钮、输入框、状态标签和留白。覆盖应用配置中的 18 个页面。

## 验证与预览边界

- 微信开发者工具自带 WXML/WXSS 编译器：18 个页面编译通过。
- 本地浏览器渲染编译后的模板：320、375、430 像素宽度，共 84 个常规与空状态检查通过，覆盖横向溢出、主要文本列溢出、事件处理函数和本地图片路径。
- 赛况逻辑回归：`node --test tests/match.test.cjs`，12 项通过。
- 首页推荐数据优先级、快捷入口和详情跳转已通过本地模拟检查。

预览图使用示例数据，并非线上比赛成绩。浏览器预览不能替代微信真机验证；系统导航栏、原生选择器、下拉刷新、键盘和真实接口仍需在微信开发者工具及手机上联调。
