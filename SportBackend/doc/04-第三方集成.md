# 第三方集成

## 华为云 OBS（对象存储服务）

### 基本信息

| 配置项 | 值 |
|--------|-----|
| 区域 | 华北-北京四（cn-north-4） |
| Endpoint | `https://obs.cn-north-4.myhuaweicloud.com` |
| 桶名称 | `wxsportproject` |
| SDK | `esdk-obs-java 3.24.9` |

### Maven 依赖

```xml
<dependency>
    <groupId>com.huaweicloud</groupId>
    <artifactId>esdk-obs-java</artifactId>
    <version>3.24.9</version>
</dependency>
```

### 认证方式

使用永久 AK/SK 认证，配置在 `OBSUtil.java` 中：

```java
private static final String AK = "你的AccessKeyID";
private static final String SK = "你的SecretAccessKey";
```

AK/SK 获取路径：华为云控制台 → 我的凭证 → 访问密钥

### OBSUtil 工具类 API

工具类位于 `com.dlust.sportbackend.util.OBSUtil`，提供以下静态方法：

#### 上传文件

```java
// 上传本地文件
String url = OBSUtil.uploadFile("banner/1.jpg", new File("C:/images/1.jpg"));

// 上传文件流
String url = OBSUtil.uploadFile("banner/1.jpg", inputStream);

// 返回值: https://wxsportproject.obs.cn-north-4.myhuaweicloud.com/banner/1.jpg
// 失败返回 null
```

#### 下载文件

```java
InputStream is = OBSUtil.downloadFile("banner/1.jpg");
// 调用方负责关闭流
```

#### 删除文件

```java
boolean success = OBSUtil.deleteFile("banner/1.jpg");
```

#### 列举文件

```java
// 列举 banner/ 目录下所有图片 URL（自动过滤目录标记对象）
List<String> urls = OBSUtil.listFiles("banner/");
```

#### 获取文件 URL

```java
String url = OBSUtil.getUrl("banner/1.jpg");
// 返回: https://wxsportproject.obs.cn-north-4.myhuaweicloud.com/banner/1.jpg
```
