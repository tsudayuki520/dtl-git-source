# SportBackend - 项目说明

## 项目简介

SportBackend 是一个体育相关微信小程序的后端服务，基于 Spring Boot 构建，为微信小程序前端提供 RESTful API 接口。

## 技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| Java | 21 | JDK 21 |
| Spring Boot | 4.0.6 | Web 框架 |
| MyBatis | 4.0.1 (starter) | ORM 框架 |
| MySQL | 8.x | 关系型数据库 |
| 华为云 OBS | SDK 3.24.9 | 对象存储（图片资源） |
| Lombok | - | 简化实体类 |
| Maven | - | 构建工具 |

## 快速上手

### 1. 环境准备

- JDK 21+
- MySQL 8.x（需启动服务）
- Maven 3.9+
- IntelliJ IDEA（建议 2025.1+）

### 2. 数据库初始化

```bash
# 在 MySQL 中执行
mysql -u root -p < sql/banner.sql
```

### 3. 修改配置

编辑 `src/main/resources/application.yml`，确认数据库连接信息：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/sport_db?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root
    password: 你的密码
```

### 4. IDEA 配置

- `Settings` → `Build Tools` → `Maven` → `Importing` → JDK 选 `21`
- `Settings` → `Build Tools` → `Maven` → `Runner` → JRE 选 `21`

### 5. 启动项目

运行 `SportBackendApplication.main()` 方法，启动成功后访问：

```
http://localhost:8080/api/banner/list
```

### 6. 同步 OBS 图片到数据库

```
POST http://localhost:8080/api/banner/sync
```

## 前端项目

微信小程序前端位于项目根目录的 `sportdocu/` 目录，使用微信开发者工具打开即可。

开发阶段需在开发者工具中勾选 **「不校验合法域名」** 才能请求 `localhost:8080`。
