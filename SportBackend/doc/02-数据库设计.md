# 数据库设计

## 数据库信息

- 数据库名：`sport_db`
- 字符集：`utf8mb4`
- 排序规则：`utf8mb4_unicode_ci`

## 表结构

### banner - 轮播公告表

存储首页轮播图信息，图片资源存放在华为云 OBS，数据库仅记录 URL。

| 字段 | 类型 | 是否必填 | 默认值 | 说明 |
|------|------|----------|--------|------|
| id | BIGINT | 是 | 自增 | 主键 |
| image_url | VARCHAR(500) | 是 | - | 图片完整 URL（华为云 OBS 地址） |
| title | VARCHAR(100) | 否 | NULL | 轮播图标题 |
| sort_order | INT | 否 | 0 | 排序序号，数字越小越靠前 |
| status | TINYINT | 否 | 1 | 状态：0-禁用，1-启用 |
| create_time | DATETIME | 否 | CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | 否 | CURRENT_TIMESTAMP | 更新时间（自动更新） |

## 建表 SQL

```sql
CREATE DATABASE IF NOT EXISTS sport_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

USE sport_db;

CREATE TABLE IF NOT EXISTS banner (
    id BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '轮播图ID',
    image_url VARCHAR(500) NOT NULL COMMENT '图片URL（华为云OBS地址）',
    title VARCHAR(100) DEFAULT NULL COMMENT '轮播图标题',
    sort_order INT DEFAULT 0 COMMENT '排序序号，越小越靠前',
    status TINYINT DEFAULT 1 COMMENT '状态：0-禁用，1-启用',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='轮播公告表';
```

### sports_meeting - 运动会表

存储运动会基本信息，通过逻辑外键关联赛程、选手、成绩等子模块。

| 字段 | 类型 | 是否必填 | 默认值 | 说明 |
|------|------|----------|--------|------|
| id | BIGINT | 是 | 自增 | 主键 |
| name | VARCHAR(100) | 是 | - | 运动会名称 |
| status | TINYINT | 是 | 0 | 状态：0-报名中，1-进行中，2-已结束 |
| organizer | VARCHAR(100) | 是 | - | 主办单位 |
| contact_phone | VARCHAR(20) | 是 | - | 联系电话 |
| venue | VARCHAR(200) | 是 | - | 比赛地址 |
| registration_start | DATETIME | 是 | - | 报名开始时间 |
| registration_end | DATETIME | 是 | - | 报名截止时间 |
| competition_date | DATE | 是 | - | 比赛日期 |
| schedule_id | BIGINT | 否 | NULL | 赛程ID（逻辑外键） |
| sign_sheet_id | BIGINT | 否 | NULL | 签名表ID（逻辑外键） |
| player_list_id | BIGINT | 否 | NULL | 选手名单ID（逻辑外键） |
| event_id | BIGINT | 否 | NULL | 比赛项目ID（逻辑外键） |
| result_id | BIGINT | 否 | NULL | 成绩公告ID（逻辑外键） |
| notice_id | BIGINT | 否 | NULL | 赛事通知ID（逻辑外键） |
| appeal_id | BIGINT | 否 | NULL | 申述表ID（逻辑外键） |
| create_time | DATETIME | 否 | CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | 否 | CURRENT_TIMESTAMP | 更新时间（自动更新） |

## 数据流转

```
华为云 OBS（图片存储）
       ↓ OBSUtil.listFiles()
  图片 URL 列表
       ↓ BannerService.addBanner()
  写入 banner 表（image_url 字段）
       ↓ BannerController.getBannerList()
  微信小程序 swiper 组件渲染
```
